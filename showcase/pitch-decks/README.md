# Pitch deck

This folder contains the selected deck in two formats:

- `GridOS_Pitch_Deck.pdf` for viewing and sharing.
- `GridOS_Pitch_Deck.pptx` for presenting and editing.

Earlier variants and pitch-generation scripts were removed to keep one canonical pair. Review all capability, performance, compliance, and integration claims in the deck against the current prototype before using it externally. The app currently uses simulated telemetry and does not connect to hardware or execute configured API/MCP tools.
